# PortfolioHub

## Project Description

PortfolioHub is a React-based Single Page Application (SPA) for showcasing creative projects.

Users are able to browse projects, search by title or category, add new projects, and view individual project details.

The application uses React for the frontend and JSON Server as a local backend.

## Features

- Display a collection of projects.
- Search projects by title and category.
- Add new projects through a form.
- View individual project details.
- Navigate between pages without refreshing.
- Fetch project data using the Fetch API.
- Save newly added projects to JSON Server.
- Responsive design for different screen sizes.

## Technologies Used

- React
- JavaScript
- HTML5
- CSS3
- React Router DOM
- Vite
- JSON Server
- Fetch API
